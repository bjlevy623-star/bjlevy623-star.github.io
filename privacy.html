Privacy Policy

Last updated: November 19, 2026

Purpose

Oscar Personal Backup is a private backup configuration operated by its owner for personal data protection. It is not a public application or commercial service.

Google Account Data Access

The application uses Rclone and the Google Drive API to access the owner's Google Drive account. Access is used to store, list, retrieve, and manage backup repository files.

How Data Is Used

Restic creates encrypted backups on the owner's server before Rclone transfers the repository to Google Drive. Google Drive is used as remote backup storage. Data is processed for the owner's backup and recovery purposes only.

Storage and Security

Backup encryption is managed locally by Restic. OAuth credentials and tokens are stored in the owner's private server configuration and are not published on this website.

Sharing

Google user data accessed by this configuration is not sold, used for advertising, or shared with third parties by the application operator.

Retention and Deletion

Backup retention is controlled by the owner. The owner can delete backup data and revoke the application's Google account access at any time.

Revoking Access

Google account access can be revoked through the Google Account third-party connections settings.

Google API Services

Use of Google data complies with the Google API Services User Data Policy, including its Limited Use requirements.

Contact

This configuration is operated privately by its owner. Contact information is provided through the application's Google OAuth support contact.
